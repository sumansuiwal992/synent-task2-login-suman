# 🔐 Login UI Page

## 📌 Project Description

This project is a **Login UI Page** developed as part of my **Web Development Internship at Synent Technologies**. The goal of this project is to design a clean, modern, and user-friendly login interface with basic functionality.

## 🎯 Purpose of the Project

The purpose of this project is to understand how login interfaces are structured and to implement a visually appealing design using HTML, CSS, and basic JavaScript.

## 🚀 Key Features

* Clean and modern login interface
* Email and password input fields
* Login button for user interaction
* “Forgot Password” option included
* Basic JavaScript functionality for interaction
* Proper alignment and spacing for better user experience

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (used inside HTML file)

## 📂 Project Structure

* **index.html** → Contains structure and JavaScript code
* **style.css** → Contains styling and layout design

## 📑 Components Included

* **Email Input Field**
* **Password Input Field**
* **Login Button**
* **Forgot Password Link**
